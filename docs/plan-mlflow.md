# План интеграции MLflow

Дата: 20.10.2026.
Основание: `docs/spec-mlflow.md`.

1. Закрыть каталоги `mlruns/`, базы данных и служебные файлы от git.
2. Подключить MLflow как необязательный режим запуска.
3. Создать родительский запуск на встречу и дочерний запуск на модель.
4. Записывать параметры, метрики, статусы и артефакты без публикации данных.
5. Сохранить слепой файл `for_eval.md` и совместимый алиас `for_opus.md`.
6. Обновить инструкции, README и контрольные задания.
7. Добавить локальные тесты чистых функций.
8. Выполнить отдельную сверку реализации со спецификацией.
