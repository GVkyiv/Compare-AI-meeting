# Сверка реализации MLflow со спецификацией

Дата: 20.10.2026.
Объект сверки: `docs/spec-mlflow.md`, `docs/plan-mlflow.md`, текущая
реализация в `compare.py`, `requirements.txt`, `.gitignore`, `AGENTS.md`.

| Требование | Проверка | Результат |
|---|---|---|
| Зависимость MLflow | `requirements.txt` содержит `mlflow>=3.0.0` | выполнено |
| Приватное локальное хранилище | `MLFLOW_DIR` указывает на `mlruns/`, каталог закрыт `.gitignore` | выполнено |
| Отключение трекера | есть флаг `--no-mlflow` | выполнено |
| Parent и nested runs | `main()` создаёт parent run, вызов модели обёрнут в nested run | выполнено |
| Параметры и метрики | параметры, метрики и статусы логируются в `compare.py` | выполнено |
| Слепая оценка | создаются `for_eval.md` и алиас `for_opus.md`, порядок записан в `AGENTS.md` | выполнено |
| Отчёты MLflow | `results.md`, `for_eval.md`, `for_opus.md`, `key.md`, `runs.json` логируются как артефакты | выполнено |
| Проверка без сети | `--rebuild` читает локальный `runs.json`, `--no-mlflow` отключает трекинг | выполнено |
| Тестируемость | чистые функции покрыты тестами в `tests/` | выполнено |

Проверка выполнена статическим чтением файлов, `py -m py_compile compare.py`
и `py compare.py --list`. Запуск внешних моделей в эту сверку не входил.
