# eval

Материал для слепой оценки. Модели запускаются на сервере пользователя,
сюда кладутся только вход и выход.

```
eval/
  prompts/            промпты, без привязки к A и B
  train/case-NN/      стенограммы, на которых правится промпт
    transcript.txt    исходная стенограмма
    A.md              выход первого варианта
    B.md              выход второго варианта
  holdout/case-NN/    то же, но открывается только для финальной проверки
```

Какой вариант скрыт за A и B, знает только пользователь. Буквы в
разных кейсах могут означать разные модели.
